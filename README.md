# phylogenetic_tree_builder
## About the Project
This tool allows the user to create a phylogenetic tree from reads/contigs.

## Functionalities
This tool first creates full sequences from the reads/contigs given. Then it creates one file with all sequences, which after this will be made into a MSA and finally will create a phylogenetic tree.

## Getting Started & Usage
To use this tool, you will need to add your data in the project and then change the data locations in the script, after this, you can run the code.
